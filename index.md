# Infinite Brain — Knowledge Bundle

An OKF v0.1 knowledge bundle with a typed knowledge-graph extension layer.
Human reader: Obsidian. Agent bridge: the Infinite Brain MCP server.
Full agent contract: [_system/AGENTS.md](/_system/AGENTS.md).
Layer mapping: [_system/OKF-MAPPING.md](/_system/OKF-MAPPING.md).
Rich agent index (all nodes by type): [_system/INDEX.md](/_system/INDEX.md).

# Concept Groups

* [pillars/](pillars/) - foundational beliefs, values, strategic principles
* [decisions/](decisions/) - recorded choices with context and rationale
* [concepts/](concepts/) - abstract ideas, mental models, frameworks
* [questions/](questions/) - known unknowns being tracked
* [playbooks/](playbooks/) - repeatable procedures
* [patterns/](patterns/) - recurring validated solutions
* [hypotheses/](hypotheses/) - testable assumptions
* [facts/](facts/) - verifiable ground truth
* [sources/](sources/) - external origin references
* [bookmarks/](bookmarks/) - saved links (unprocessed)
* [notes/](notes/) - freeform capture
* [contacts/](contacts/) - named people with metadata
* [references/](references/) - glossary / terminology
* [events/](events/) - timestamped occurrences
* [tasks/](tasks/) - actionable items
* [custom/](custom/) - domain-specific nodes (see _system/LOCAL-TYPES.md)

# System

* [raw/](raw/) - immutable inbox for source material
* [logs/](logs/) - one log node per operation (not indexed)
* [_system/](_system/) - schemas, agent rules, index
* [_templates/](_templates/) - node template
